Chunking a list
Here's a small, dependency-free helper. It yields lists of at most n items:
Python
def chunked(xs: list, n: int):
"""Split xs into lists of size n."""
if n < 1:
raise ValueError(...)
for i in range(0, len(xs), n):
yield xs[i:i + n]
# keeps original order
